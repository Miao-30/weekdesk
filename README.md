# 周序课表：南京中医药大学 Windows 桌面课表

**周序课表（Weekdesk）是专门为南京中医药大学教务系统设计的 Windows 桌面课表与本地待办工具。**

它会从“我的课表”读取当前学期的教学安排，按北京时间自动计算教学周，清晰显示每周课程、教师、校区、教室和节次；同时提供独立的待办、重复任务和系统提醒功能。

课程、待办和登录会话只保存在本机，不上传第三方服务。

## 下载与首次使用

前往 [Releases](https://github.com/Miao-30/weekdesk/releases) 下载最新的 `Weekdesk-Setup-1.2.0.exe`。

1. 安装并启动“周序课表”。
2. 点击“登录教务”，在程序内打开南京中医药大学教务系统并自行登录。
3. 首次同步会读取当前学期课表，并逐周校验课程、教师、地点和节次。
4. 后续会在启动、每小时、恢复联网和电脑唤醒后自动同步，也可以手动刷新。

程序不保存教务系统密码，只保留本机网站登录会话。

## 主要功能

### 课表

- 以周视图显示周一至周日和完整节次时间轴。
- 自动处理单双周、不连续周次、停课周、晚课和不同周次的教室变化。
- 当前周课程使用低饱和色卡片显示，非本周安排以灰色标注“【非本周】”。
- 点击课程可以查看课程代码、班级、教师、地点、周次和教务来源信息。
- 网络课和未排时间课程保留在底部入口，不虚构上课时间。
- 支持上一周、下一周、返回本周、周次选择、置顶、托盘收起和窗口设置。
- 浅灰背景、细网格线、近直角课程卡片和 10–18px 字号设置，适合长期放在桌面查看。

### 待办

- 独立的“今天 / 近期 / 全部 / 已完成”页面，并记住上次打开的位置。
- 支持快速新增、编辑、完成、撤销、删除、搜索、标签筛选和排序。
- 支持高、中、普通三档优先级，以及无截止日期任务。
- 支持关联当前课表课程，课程被教务系统移除后仍保留原任务并提示状态。
- 支持每天、每周、每月重复；月末日期会自动落到目标月份最后一天。
- 支持截止时、提前 10 分钟、1 小时或 1 天提醒。
- 程序收起到托盘后仍可提醒；启动或唤醒后会补发未完成的逾期提醒。

## 数据与隐私

- 本地数据保存在 `%APPDATA%\\Weekdesk\\schedule.json`。
- 课程、待办、界面状态、窗口位置和偏好均保存在本机。
- 教务同步只在新数据完整解析并校验后替换旧缓存；断网、登录过期或页面变化时保留上次成功数据。
- 教室缺失时显示“教务系统未填写”，不会猜测地点。
- 本项目不会上传课程、待办或登录信息。

## 开发与验证

需要 Windows 和 Node.js 24：

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run build
npm.cmd run package
```

安装包输出到 `release`。不连接教务系统的本地预览：

```powershell
npx.cmd tsx scripts/preview.ts
npm.cmd run dev
```

主要目录：

- `src/ScheduleView.tsx`：课表页面和课程详情。
- `src/TodoView.tsx`、`src/todo-core.ts`：待办界面、筛选、重复和提醒计算。
- `src/extract.ts`、`src/core.ts`：教务页面解析和北京时间周次计算。
- `electron/main.ts`：登录、同步、托盘、窗口设置和系统提醒。
- `electron/store.ts`：本地存储、旧版迁移和原子替换。

`tests/fixtures/school-all.json` 是完全虚构的公开演示课表，只用于测试和界面预览，不包含任何个人课表数据。
