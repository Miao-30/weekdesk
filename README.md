# 周序 · Windows 桌面课表与待办

校园教务系统的个人周课表与本地待办程序。使用 Electron、React 和 TypeScript 开发；课程、待办和提醒均保存在本机，不上传第三方。

## 安装与首次使用

1. 安装 `Weekdesk-Setup-1.2.0.exe`，从桌面“周序课表”快捷方式启动。
2. 点击“登录教务”，在学校页面自行登录。程序只保留本机网站会话，不记录密码。
3. 首次同步会读取并逐周核对当前学期课表。启动、每小时、电脑唤醒和恢复联网后自动同步，也可手动同步。
4. 默认不置顶、不开机启动。右上角可切换置顶、打开设置或收起到托盘；双击托盘图标恢复，右键可退出。

## 课表

- 顶部仅保留日历图标、课表/待办导航和窗口按钮；紧凑工具栏集中显示周次、日期范围、切周、非本周开关和同步状态。
- 星期表头只显示周一至周日；今天用浅色列背景和强调线标识，不再额外显示日期数字。
- 浅灰背景、细网格线和近直角课程卡片减少视觉占用。设置中的文字大小支持 10–18px，行高会随字号一起缩放。
- 日期按北京时间更新，支持上一周、下一周、返回本周和周次下拉选择。
- 灰色“【非本周】”表示该安排的周次不包含正在查看的周；同格安排可展开查看。
- 点击课程卡片可查看教师、地点、周次、班级、课程代码和教务来源原文。
- 网络课和未排时间课程保留在底部“查看全部”入口。
- 同步成功只显示绿色状态点；鼠标悬停可看最后成功时间。登录失效、断网或页面变化时会保留上次完整缓存并显示原因。

## 待办

标题栏的“课表 / 待办”可切换独立页面，程序会记住上次页面。待办徽标显示已逾期或今天到期且尚未完成的数量。

- “今天”包含今天截止、已逾期，以及今天创建且无截止日期的任务；“近期”显示未来 7 天；另有“全部”和“已完成”。
- 顶部输入标题并按 Enter 可快速新增。点击任务可打开完整编辑面板，填写备注、日期时间、优先级、课程、提醒、重复和标签。
- 支持搜索、标签过滤，以及按截止时间、优先级或创建时间排序。
- 课程关联使用课程代码保存，并显示课程颜色。课程之后从教务课表移除时，任务仍保留原课程名称并明确标记。
- 支持每天、每周、每月重复。完成重复任务会生成下一次实例；月末会自动落到目标月最后一天。撤销完成只恢复原实例。
- 提醒可设为截止时、提前 10 分钟、1 小时或 1 天。程序收起到托盘后提醒仍运行；启动或唤醒后会补发尚未提醒且未完成的逾期提醒，每个任务实例只提醒一次。
- 删除任务前需要再次确认；完成任务保留在“已完成”中。

Windows 通知需要任务同时填写截止日期和时间，并允许“周序课表”发送系统通知。若选择“退出程序”，提醒将在下次启动前暂停；收起到托盘不影响提醒。

## 数据与隐私

课程、待办、界面状态和偏好保存在 `%APPDATA%\Weekdesk\schedule.json`，采用临时文件写入后原子替换。从 1.0 或 1.1 升级时，原课表缓存、待办、网站登录会话、窗口位置、透明度、字号、置顶与开机启动设置都会保留。

网站会话使用程序自己的持久分区。教务同步只在新数据完整解析并校验后替换缓存。学校尚未更新到“我的课表”页面的临时调课通知，程序无法提前获知；地点缺失时如实标注“教务系统未填写”，不会推测。

## 开发与验证

需要 Windows 和 Node.js 24：

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run build
npm.cmd start
npm.cmd run package
```

安装包输出到 `release`。本地界面预览（不连接教务）可运行：

```powershell
npx.cmd tsx scripts/preview.ts
npm.cmd run dev
```

主要结构：

- `src/ScheduleView.tsx`：紧凑课表工具栏、课程网格和详情。
- `src/TodoView.tsx`、`src/todo-core.ts`：待办界面、校验、筛选、重复与提醒计算。
- `src/extract.ts`、`src/core.ts`：教务页面读取、周次解析和北京时间周次计算。
- `electron/main.ts`：登录同步、受限 IPC、托盘、窗口设置和系统提醒。
- `electron/store.ts`：本地存储、旧版迁移和原子替换。

`tests/fixtures/school-all.json` 是完全虚构的公开演示课表，用于测试和界面预览；正式程序不会把演示数据当作实时课表。
